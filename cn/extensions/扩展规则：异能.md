# 1 基本

## 1.1 能力点概述

添加新的属性：能力（POW）。在建卡时，你需要用2属性点购买1 POW。POW属性的最大值为10，你不能在建卡时提升这个属性到大于10。

POW可以被解释为任何来源的”异能”能力和它的使用技巧。

每升级一点POW需要 {当前POW值*2} 的CP。

## 1.2 创建凡俗角色

没有任何POW属性的人物在建卡时会额外获得5属性点和10技能点，自由分配。分配这些技能点的技能无法将任意技能升级至对应的属性值更高的等级，如你的角色拥有7 REF，那么你使用了这些技能点升级的步枪技能只能使用这些属性点升级到最高7级。

凡俗角色只能从剧情里获取POW属性，无法通过CP升级。

## 1.3 技能简述

任何非凡俗角色需要选择一个能力组，能力组有不同的选择时需求，单独的技能由能力组提供。

# 2 能力组

在建卡时，如果你的角色并非凡俗角色，那你需要选择一个能力组。能力组是一系列技能与动作的合集。能力组随着POW属性升级。

## 2.1 能力组：通用（需求：三个7以上的属性，其中包含幸运7+）

“Jack of all trades, expert of nothing.”

### 2.1.1. 能力组：通用 简述

通用能力组提供使用者在多种情况下的不同能力，以”创造”和”影响”为核心概念。 使用此能力组的角色可以与”法师”类比。

### 2.1.2 能力组：通用 技能树

通用能力组包含以下技能：创造，改变。你如常购买这两个技能，并且如常对其进行升级。

**创造 / 闪铸武器**

凭空创造武器。你创造的武器会于下一次战斗结束后自动分解。在非战斗情况下花费10分钟，战斗轮内花费一个整轮时间。规则如下。


| 基础难度                | POW+创造+相应武器类型 vs. 如下难度 * 伤害骰 | 描述                          |
| ------------------- | ---------------------------- | --------------------------- |
| **伤害骰数量**           | 每个+1                         | &nbsp;                      |
| **高于0的准确度**         | 每点+1                         | &nbsp;                      |
| **属性：近战武器**         | *0.5                         | 任何具有2米以内攻击距离的武器             |
| **属性：远程武器和枪械**      | *2                           | 弓箭，枪械                       |
| **属性：投掷武器**         | *3                           | &nbsp;                      |
| **属性：D4武器**         | *0.5                         | 手枪或者轻型刀具                    |
| **属性：D6武器**         | *3                           | 通常来说，步枪口径或者双手剑（Zweihander）。 |
| **属性：D10武器**        | *6                           | 火炮或者大当量爆炸物                  |
| **属性：制导武器，重武器或者火炮** | *4                           | 导弹，高于.50bmg的口径，线膛或者滑膛火炮     |
| **附加：伤害值**          | 每点+1                         | 最高不高于伤害骰，应用在计算后             |


你制作的武器应该具有至少一个伤害骰。  
  
如制作一把5.56mm的突击步枪，5.56mm武器具有4d6+2的伤害和+2准确度。 你需要投掷 POW+创造+步枪 vs. { 4（伤害骰）*3（D6武器）*2（枪械） }。如此制造的武器总是有无限弹药，且不需要换弹。

在失败的情况下，你依然能成功制造它，但它于1d4-1轮后损坏。这是一个暗骰，玩家不应该知道其是否成功或失败。

大失败意味着你花费了双倍时间并且创造失败。

**创造 / 闪铸物件**

创造一件能存在1日的物件。”过于简单的工具”或”不带来任何增益的工具”，如日常服装，被视为自动成功。非战斗情况下花费30分钟，战斗轮内花费2轮。

| ----------- | ---------------------- | ---------------------------------------------------------------------------- |
| **简单工具**    | 10                     | 开锁工具，镜子，扳手，硬币                                                                |
| **普通工具**    | 15                     | 扬声器，收音机，纸币                                                                   |
| **复杂工具**    | 20                     | 微型 / 纽扣窃听器，手机，电脑                                                             |
| **属性：护甲**   | *2                     | 这个设备给予穿戴者 +10 以上的SP。                                                         |
| **属性：本地联网** | *3                     | 这个设备需要加入一个本地联网（举个例子，闭路电视和门禁系统）工作。该词条和远程联网互斥。注意：这不是"依赖无线电工作（如收音机）"。           |
| **属性：远程联网** | *4                     | 这个设备工作所需的数据在一台远程服务器上，如信用卡，手机（SIM）卡，联网的假证。该词条如果和"本地联网"出现在同一个设备上，只使用本词条进行难度计算。 |


在失败的情况下，它无法正常工作（如一个镜子缺少镀层，硬币的重量错误）

大失败意味着你花费了双倍时间。

**改变 / 影响行动**

你为POW*5米内的可见目标下一个声明的动作提供 {高于难度的成功数} 点加成或减值。


| 基础难度      | 1D10+POW+改变 vs. 难度         | 描述                                   |
| --------- | -------------------------- | ------------------------------------ |
| **目标：自身** | 10                         | 你强化或者削弱自身的下一个行动。                     |
| **目标：他人** | 15 或 5 + 目标的 {1D10+改变+POW} | 你强化或者削弱有效范围内一个目标的下一个行动。针对自愿的生物，自动成功。 |
| **目标：其它** | 20                         | 你的目标是一个不具有阵营的单位。                     |


这个动作消耗一个标准动作。在失败的情况下，目标转而获得{离成功的距离}成功数减值或加值（根据你的意图所示）。

大失败将对目标造成{离成功的距离}点不可抵挡的伤害，无论目标是否对你友善。如果目标是物体，直接对SDP造成伤害。

**改变 / 塑材**

消耗标准动作，你为目标的SP增减 { 强度 }点数或者{额外成功数}，或者重塑一片地形。 目标不能是生物本身，但可以是穿着的某件衣物 / 某个设备。 效果留存24小时，或到下一场战斗结束。 你也可以改变一个触及区域内地形的材质，或者改变物体特征并增减其SP和SDP。

| **目标：大型物品**     | 15                 | 你无法用双手移动的物品。  |

| **距离：触及**       | *1                 | 触手可得之物。       |

失败的情况下，目标不受影响，有意识的目标会意识到你在对其进行这个行动。 大失败的情况下，效果相反，成功数视为 {距离成功的成功数} 。

你显然能增加或降低你弹药的穿甲。你可以将你的弹药提升或降低{强度}点穿甲，但最多上调或下调一级。

## 2.2 能力组：空间（需求：INT 7+ CON 7+）

注重功能性和隐秘行动的技能组。灵感来源于太空死灵。

**置换 / 放置传送门 固定3点技能点**

放置一扇单向的传送门，它只能被使用能力组：空间的角色发现和使用。

针对瞬发的放置传送门，投掷1D10+POW+置换 vs. 暗骰1d10+距离（50m内为-5，500m内为0，2000m内为15，5000m内为20，7km以内为25，高于7km为30）。

你可以花一个小时稳定目标地点的空间范式来让这个检定自动成功。你需要在传送门两端都如此进行这样的行为。

无论如何，你同时只能维持最多POW/3（向上取整）个传送门。

**置换 / 虛空行走 Riftwalk（特殊：每日最多POW*3次）**

传送到视野内距离最多 POW*5米的任意一点。 这取代你每轮的移动动作。

**空间 / 现实穿甲弹 AP-R | 虚空斩击 | Void Slash（特殊：每日最多POW次）**

强化你的下次射击，使其忽略其遇到的下一个掩体或护甲的AR（但不忽略伤害免疫），或者你的下次近战攻击直接造成SP伤害。  
通常来说，这使用一个动作，并且涉及到与子弹或武器的直接接触。

> 狙击手在房区透过看着几百米外大道上路过的BMP。她的任务是（通过某种方式）瘫痪前来增援的装甲车，顺便解决所有乘员，为在FOB坚守的队友赢得一点时间。  
> 东欧并不是世界上最好的地方。  
> 手中的MK1改件 SVDK哪怕搭配SNB（7.62x54mm R SNB (7n14), 伤害 5D6+3, 穿甲60）显然没法解决驾驶位的加厚均质钢装甲（AR 130），在500米外击中其观察窗的防弹玻璃（AR 75）也绝非易事。她握住手中的子弹，拉开枪栓并将其从侧面装入。  
> 扣动扳机时，弹头从枪口消失——下一瞬间，刷新在驾驶员的头上。在那之后，消音器的枪口吐出火焰和火药粒子，在那之后，后坐力传到狙击手的肩膀，在那之后，月光照耀着的窗框上灰尘飘飞。  
> 狙击手甩甩衣服上的灰尘，向后走入其设置的传送门。又一天的工作。

**置换 / 心灵致动 Telekinesis（特殊：每日最多POW次）**

消耗一个动作，进行1D10+POW+置换 vs. 难度（5米内的任何地点10，可见位置15，不可见位置20）你将一个不高于你极限负重的单位传送到目标地点。

## 2.3 能力组：红魔法（需求：CON 6+ CHR9+）

依赖你自己生命力的技能组。以你自己之力。

### 2.3.1 红魔法 简述

幻想过对着你的敌人丢出劲爆闪电箭么？魔能爆，不过不是戏法？魔法飞弹？还是不够劲？血魔法？邪魔法？火球术？哦，我们家里有火球术。

不管怎么说，你获得一个新属性：MAG（这与其它魔法扩展的MAG属性通用）。它具有你的WIL+POW点数点。你需要消耗这种资源来施法。哪怕我们都知道这来自于异能（在无限里，它具有特异本质而非魔法本质），但我们认为这是更好的描述方式，且可以与一系列后续的扩展更好地兼容。

每当你进行一次8小时以上的休息或者进入新章节，这个属性会被自动补满。

### 2.3.2 红魔法 技能树

**塑魔 / 攻击**

你使用你的能力攻击。你可以选择一个表现形式（如元素，符文或者随便什么），选择支付法术强度，然后依照如下效力表进行一个1D10+剩余MAG+POW+塑魔的攻击检定。  
法术强度被视为在你难度上的加值，如果检定成功，其转而视为你的额外成功数并计入伤害。每附加一个额外效果，你支付 1额外 MAG。任何攻击需要效果线。

在大成功的情况下，你无论如何都能成功进行这次攻击。


| 类型        | 难度       | 描述                                                                                                                           |
| --------- | -------- | ---------------------------------------------------------------------------------------------------------------------------- |
| **攻击：基础** | 10+法术强度  | 针对单体目标进行攻击。这是一个被视为近战攻击检定，但防御者进行反射豁免或意志豁免 vs. 你攻击出目+法术强度的攻击。如果成功，出目和防御的差值被视为实际造成的伤害。这次攻击忽略任何护甲。                               |
| **目标：区域** | +5/每0.5米 | 在基础掷骰上，转而造成区域伤害。所有在区域内的目标进行反射或意志豁免。这次攻击忽略任何护甲。                                                                               |
| **目标：多锁** | +2/每目标   | 额外对{目标数}个目标造成伤害。                                                                                                             |
| **元素：火**  | +3/每0.5米 | 在目标：区域的情况下，你的攻击视为一个具有与你难度相符（如一个0.5米致死半径的攻击需要10+5+3=18点）致死半径的高爆爆炸物。 在目标：单体的情况下，其直到使用一个整轮动作灭火前，在这轮之后的每轮受到额外5伤害，均分在四肢（每个部位1伤害）。 |

| **元素：传染** | +3       | 在目标：单体或目标：多锁的情况下，你进入专注状态，直到受到任何伤害或开始施放任何其它需要专注的法术。每轮传染POW米内1D{POW}个额外敌对单位，其需要进行同样的检定，否则每轮造成同样的伤害。                            |

| **元素：陷阱** | +2/米     | 直到目标满足一个触发条件并在触发距离内，这一法术才会生效。这一法术会对任何在触发距离内的目标应用。                                                                            |

**塑魔 / 治疗**

你如你所愿一样恢复你的肉体。你进行1D10+剩余MAG+塑魔 vs. 你的最大受击点数（总生命值），每支付1额外法术强度获得1额外加值，恢复成功数点受击点数到你的任意肢体。这可以恢复已经被摧毁或被分离的肢体，但在被分离的肢体的情况下，你需要两倍肢体受击点数的成功数才能将其恢复。这是一个整轮动作，你不能将其缩减。

> 红魔法师被逼入死角。敌人正在从四面步步紧逼——但红魔法师脸上挂着自信的微笑。  
> 汹涌的法力在体内澎湃，红魔法师伸出左手，七色冷光从指间流出。  
> 另外一端的黑色中探出枪口，在深蓝的影子中伸长。橙色的枪焰在下一瞬间照亮整个小巷，在一切平息时，红魔法师依然站在原地，聆听着弹壳的落地声，嘴角挂着那抹从开始时就一直在那里的微笑，毫无惧意。

## 2.4 能力组：绿魔法（需求：ATTR 6+ CHR9+）

高强度自然亲和力，以四大元素和世界为桥梁的技能组。

在选择绿魔法的情况下，你立即无代价获得以下能力：

### 万物同调 Synchronize

你可以与任何动植物交流。这包括但不限于菌系，草木和菌群。

### 神言 God-Tongue

你了解一种新语言。可与任何对象使用这种语言交流，而无需获得其先决语言知识。你可以听说读写任何语言，方言，无论其是否还在被任何对象使用，是否已经灭绝，或有多古老，且其在被听到的人中视为母语（但并非母语）。你写下的内容可被任何可以阅读的生物阅读并立即理解，反之亦然。

### 心灵传音 Telepath

你可以通过一个动作和一个自愿的目标绑定，你无需任何设备即可与其在你的{POW*100}距离内交流，这种思维是双向和即时的且可传递任何信息。

### 同一感知 Uniperception

你的侦察距离（听觉/嗅觉/视觉）*2，并获得低光视觉，黑暗视觉和红外视觉。

### 环境亲和 Eco

你不再需要进食，休息，或呼吸——而无需受到任何惩罚。

你获得一个属性，MAG，默认上限等于你的CHR+POW。你在污染越严重的地方，其上限就越低。在都市环境中，你只有2/3的可用MAG，在中度污染环境中，你只有1/2的可用MAG。在重度污染环境中，你只有1/3的可用MAG。  
在你离开一个旧的生物群系进入一个新的生物群系（针对自然环境，每5公里距离）时，你重新补满你的MAG点数或在进行一次长休后补满你的MAG点数。  
除此之外，你可以使用以下法术：

### 换型 Shapeshift 3MAG

你花费一个整轮动作，进入一个你所选的，在你所处生物群系内有出现的动物形态。这一形态必须是你见过活体的。你获得其所有物理属性和其表达允许的外形。你可以无限期处于这一动物形态，而不需要维持。

### 播种 Seed 1-5MAG

你花费一个动作，让一个种子状态的植物立即生长为成体。针对于一年生草本植物，1MAG，针对于多年生草本植物，2MAG，针对乔木，3MAG，针对真菌，5MAG使其形成菌群，针对木本植物，5MAG。

### 引导生长 Controlled Growth 2MAG

你花费一个动作，引导一株植物如你所愿生长。其可以提供任何其允许且你想要的效果，如一颗木本植物可以成为你的掩体或为你提供居所，草本植物可以遮蔽视线。投掷1D10+POW+CHR vs. 20，在成功的情况下，你可以达成效果。

### 放逐术 Banish 1MAG

你进行一次攻击动作，并造成伤害。通过当前的时间，其有不同效应。你进行1D10+MAG+CHR检定。

在日间，这被视为一次远程攻击，目标为最多POW*10m内的目视内任何一点，并具有1m半径，造成2D6点忽略护甲的伤害，分摊至目标全身，对抗反射或强韧豁免。这同时治疗你选中的任何区域内单位2D6受击点数。你可以通过专注维持这个法术使其持续超过1轮，并将其移动最多10m。  
在夜间，这被视为一次远程近战攻击，目标为POW*20m内的任何单位。对方进行近战攻击抵抗，正常投掷身体部位，你造成胜出点数，忽略护甲的伤害。  
在清晨和傍晚，这被同时视为一次远程和近战攻击，目标为POW*20m内的任何单位。对方使用感知豁免，你造成等于胜出点数的，忽略护甲的伤害。

### 治疗术 Heal 2MAG

你进行1D10+POW+CHR vs. 目标的最大受击点数（总生命值），你每支付一点额外的法术强度，获得2点额外必定成功的治疗效果。你可以选择任何对象，而非必须是人形生物。  
恢复成功数点受击点数到目标的任意肢体。这可以恢复已经被摧毁或被分离的肢体。这是一个整轮动作。

### 群体治疗 Group Heal 1MAG / 轮

你回复你身边每个你选定的对象的受击点数，每轮1D6，到其任意肢体。你在开始时每支付1点额外的法术强度，你获得1点额外的治疗效果。你每轮需要支付一次MAG。

### 隐形术 Invisibility 1MAG

你进入隐形术的专注状态，并掷1D10+POW+CHR vs. 15。每点成功提供你1轮的额外隐形。只要你在自然环境内，你在回合内的第一次攻击或动作不会打破隐形。

### 土遁术 Doton 2MAG / 动作

你获得当前自然环境的容许。你可以以双倍速度移动，或每轮使环境替你进行一个额外的动作（相当于获得1无视距离的免费动作）。

### 复活 Resurrect 特殊

你如在自然环境内，每章节一次，你在本章的第一次死亡豁免检定必定成功，且你在进入死亡状态时会在一个你选定的，在本生物群系内的安全地点以1HP复活。你每章节只能使用最多一次此能力。

### 许愿术 Wish 剩余的所有MAG

一章节一次，你骰1D10+POW+CHR，在你获得大成功或出目>35时，允许GM满足你的一个合理范围内的要求。你可以使用此技能无需掷骰即可恢复你所有的MAG或一个特定单位的全部受击点数。如此使用时，你可以再生目标目前状态为分离的肢体，你无法复活单位，但你可以立即结束其所有不良状态（哪怕这个状态将目标限制为死亡状态）。

## 2.5 能力组：肉体（需求：BODY 7+ CON5+）

类比Shadowrun修士的技能组，永久且强力的属性加成和新动作。数值是武术最终极的奥义。

你使用你的POW永久购买以下技能中的任何技能。一经购买，你无法退回任何你已购买的技能。

### 枪械同调 Gunjack 0.5POW

你的射击骰在任何情况下都获得+5加值。你不可重复购买这个增强。

### 动如脱兔 Wired Reflex 1POW

你永久获得一颗额外的1D10主动性。你在重复购买这个增强时，只需要支付0.5POW。

### 飞檐走壁 Wall-Run 0.2POW

你现在可以在最陡垂直的墙面上以全部移动速度步行，这些墙面被视为平地。

### 遁入暗影 Into the Shadow 0.5POW

你可以在任何时候使用一个自由动作进行潜藏检定，对抗成功则无法被选中，直到你的下个动作，或者进行攻击时解除，但每个战斗轮内只能进行一次。

### 厚实表皮 Thick Skin 0.2POW

你获得额外的10 AR作为天生护甲，这个护甲值和任何你穿着的护甲累加且不受到惩罚。你可以重复购买这个增强。  
在你购买5次后，轻武器（5.56）不再对你造成伤害。

### 触杀术 Killing Touch 0.2POW

你的徒手攻击造成额外的2伤害。这个伤害不可被抵消。

### 天生优越 Born Better 0.5POW

你永久增强你的一点属性，包含LUK但不包含POW。你可以重复购买这个增强。

### 载具共感 Vehicle Sympathy 0.3POW

你指定一类载具，你无需训练，在任何操作检定上获得固定的25出目，除非你决定进行一次单独的检定，在这种情况下取高。

### 谋杀驱动 Kill Action 5POW

你在将一个单位通过近战从满血置入死亡豁免（或死亡），且贡献全部伤害的情况下，立即获得一个额外的免费标准动作和一个免费的移动动作，并获得MOV*0.5的额外移动力。这个移动力可以忽略你的默认移动距离上限。所有来自这个强化的加成可以无限次叠加。

### 全能吸血 Omnivamp 1.5POW

在造成伤害时，如果这次攻击是近战攻击，你回复{你造成的全部近战伤害}受击点数，或回复你一半的{远程攻击造成的伤害}受击点数。这和鲜血治疗不兼容。

### 鲜血治疗 Heal-on-Kill 1.5POW

在你击杀一个目标时，治疗你50%生命值。这和全能吸血不兼容。

### 快速换弹 Fast Reload 0.2POW

你所有涉及轻武器换弹和重新装填的动作需求等级下调一级。

### 子弹时间 1.5POW

你所有远程攻击视为瞄准1轮，并且距离减值下调一级。

### 二段跳 Doublejump 0.2POW

你不再受到摔落伤害，且你的跳跃高度x2。

### 天资异禀 Exceptional Aptitude 0.5POW

你永久增强你的一点任意技能。你可以重复购买这个增强。

### 飞行术 Flight 0.3POW

你可以使用你的移动动作飞行最多1/4移动距离的距离，且你不再受到摔落伤害。在回合结束后，你正常落地。在移动后保持悬浮需要使用标准动作。

### 透视 Wallhack 1POW

你可以感知到实心墙体后的任何生物或物体的精确位置。这允许你对其发动攻击，但你的攻击仍需考虑掩体的护甲AR和可能的遮挡惩罚。

### 如臂使指 0.3POW

你的任何近战攻击获得2米攻击范围，针对攻击范围已有2米的情况，你获得额外2米攻击范围。

### 反击风暴 Open Feedback 1POW

你在战斗轮中的一个额外攻击不再受到-3主动性惩罚。如你购买了一级反击风暴，在你每轮进行两次攻击时，你受到0行动减值，在进行三次攻击时，你受到1行动减值。

### 如有神助 Ex Machina 1POW

你不再受到任何大失败惩罚或失败惩罚，只有普通的失败效果。

### 多播 Multicast 1.5POW

你在每个战斗轮中获得一个额外的免费标准动作。你可以重复购买这个增强。

### 刀锋舞者 Bladedancer 1POW

你可以使用一个动作召回任何你投掷的投掷武器，其在返回路径上造成你投掷时的伤害，并且你的任何持械近战攻击造成3不可抵消的伤害。

### 自然治疗 Breath Healing 1POW

你获得5被动生命回复/每轮。你可以重复购买这个增强。

### 闪现 Flash 1POW

你可以使用一个移动动作向任意方向瞬间位移五米。如果你将你本轮的移动动作放置在特定角色的攻击动作之后，你不再受到这个攻击。使用移动动作（或提前支付移动动作）你可以免疫你每轮第一次受到的投掷物攻击。

### ESP ESP 1POW

你不再能被作为伏击的目标，且在目标对你有伏击意图时，你总是能对其进行精确定位。

### 隔空取物 Telekinesis 1POW

你可以抓取你POW米内的任何物体，只要你的BODY允许你那么做。
