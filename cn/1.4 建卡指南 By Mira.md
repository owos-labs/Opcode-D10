# **在 Opcode:// D10 创建你的第一个角色**

***作者：Mira @ Occurrence Labs***

---

**嘿，欢迎来到千禧年——和 Opcode:// D10 的世界。**

**第一次打开角色卡的时候，你可能盯着那些属性和技能表格发呆。别担心，我第一次也是。这篇指南会带你一步一步走完整个过程，以 30属性点购 为例，不包含扩展规则**

# **第一步：了解你的属性**

**在 Opcode 里，你的角色由六个核心属性定义。每个属性的范围通常在 2到10 之间，5是普通人水平，8以上已经是人类顶尖了。**


| **属性**  | **全称** | **它管什么**                  |
| ------- | ------ | ------------------------- |
| **BOD** | **体质** | **身体强壮程度、抗揍能力、能拎多重的东西**   |
| **REF** | **反射** | **反应速度、手眼协调、能不能接住飞过来的东西** |
| **WIL** | **毅力** | **意志力、抗压能力、能不能在紧张时稳住**    |
| **INT** | **智力** | **推理能力、学习速度、能不能想出好点子**    |
| **CHA** | **魅力** | **社交能力、说服力、别人喜不喜欢你**      |
| **LUK** | **幸运** | **运气好不好、能不能在关键时刻翻盘**      |


> ***💡 新手提示：你不必每个属性都很高。一个角色有短板才真实——你的角色可能是聪明但体弱，或者社交牛逼但做事冲动。***

---

## **第二步：分配你的30点属性**

**我们在本教程内使用30buy。**

**30属性点购的意思是：你一共有30点，分配到六个属性上。每个属性的最低值是2，最高值（建卡时）不超过8。**

**一个简单的办法是：先想清楚你的角色是干什么的。**

**比如说，我想创建一个文职编辑的角色——一个在仓津市某个小工作室上班的年轻人，日常工作是整理稿件、约稿、泡咖啡馆写文案。**

**那我会这么想：**

- **INT 智力：编辑的本钱，要高。→ 8**
- **CHA 魅力：要跟作者、客户打交道。→ 6**
- **WIL 毅力：截稿压力大，得扛得住。→ 5**
- **REF 反射：不用特别高，但至少能接住掉落的笔。→ 4**
- **BOD 体质：不擅长体力活。→ 3**
- **LUK 幸运：运气嘛，偶尔会好。→ 4**

**加起来：8+6+5+4+3+4 = 30 ✅**

**你可以用这个模板来思考你的角色：**


| **属性**  | **你的值** | **为什么给这个值？**   |
| ------- | ------- | -------------- |
| **BOD** | **?**   | **你的角色体力怎么样？** |
| **REF** | **?**   | **手残还是灵活？**    |
| **WIL** | **?**   | **遇到压力会慌吗？**   |
| **INT** | **?**   | **聪明还是大条？**    |
| **CHA** | **?**   | **社牛还是社恐？**    |
| **LUK** | **?**   | **运气站在你这边吗？**  |


> ***💡 新手提示：不用追求"均衡"。一个 INT 8 / BOD 2 的角色比全属性5的角色更有意思——短板创造故事。***

---

## **第三步：计算衍生属性**

**确定核心属性后，你需要算几个衍生值。这些在游戏中会用到：**

**移动速度 (MOV) = (BOD + REF) × 2，单位是米/轮**

**我的编辑：BOD 3 + REF 4 = 7，×2 = 14米/轮**

> ***差不多是全力冲刺时能跑过一条小巷的距离。***

**感知距离 (SENS) = (REF + WIL) × 2，单位是米**

**我的编辑：REF 4 + WIL 5 = 9，×2 = 18米**

> ***大概能听清街对面有人在说什么。***

**受击点数 (HP) = (WIL × 0.5 + BOD × 2) + 3**

**我的编辑：WIL 5 × 0.5 = 2.5，BOD 3 × 2 = 6，+3 = 11.5 → 向上取整 12**

> ***意味着你挨不了几拳。所以——别打架。***

---

## **第四步：选择技能**

**现在到了让你的角色真正鲜活起来的步骤。**

**Opcode 有一套固定的技能列表。每个技能关联一个或多个属性，你需要根据角色的背景来决定哪些技能高、哪些低、哪些根本不点。**

**新手分配建议：**

- **想象你的角色最擅长什么，把那1~2个技能点到 6~7**
- **想象你的角色日常会做什么，把那3~4个技能点到 3~5**
- **剩下的技能要么 1~2，要么 0**

**用我的编辑举例：**

**核心技能（饭碗）：**


| **技能**    | **点数** | **为什么**              |
| --------- | ------ | -------------------- |
| **图书馆**   | **7**  | **查资料、翻档案是编辑的基本功**   |
| **知识**    | **6**  | **什么话题都能接上，才能写好稿子**  |
| **专注/洞察** | **5**  | **审稿找错字、发现别人没注意的细节** |


**社交技能（混口饭吃）：**


| **技能**    | **点数** | **为什么**            |
| --------- | ------ | ------------------ |
| **说服/交涉** | **5**  | **约稿、谈价、安抚暴躁的作者**  |
| **魅惑/煽动** | **3**  | **在派对上混个脸熟，套点消息**  |
| **伪装**    | **2**  | **见人说人话，进不同场合换气质** |


**生活技能（活下去）：**


| **技能**      | **点数** | **为什么**          |
| ----------- | ------ | ---------------- |
| **侦察**      | **3**  | **找东西、发现隐藏的细节**  |
| **器用**      | **2**  | **会用电脑、打印机、传真机** |
| **沉着/药物抵抗** | **2**  | **喝了酒还能保持清醒**    |
| **潜藏**      | **1**  | **不想被打扰的时候能溜走**  |
| **运动**      | **2**  | **跑两步还行，别追太久**   |
| **巧手/特技**   | **1**  | **也许运气好能撬个锁？**   |
| **医疗**      | **1**  | **会贴创可贴的程度**     |


**总计：7+6+5+5+3+2+3+2+2+1+2+1+1 = 40点**

> ***💡 新手提示：如果你的角色完全没点某个技能（比如「自然」=0），意味着他分不清枫树和橡树——这很合理。没人什么都懂。***

## **第五步：给你的角色加点血肉**

**数字填完了，现在是最有趣的部分——让这个角色活起来。**

**问自己几个问题：**

1. **她叫什么名字？**
  - **我的编辑叫 Mira。听起来简单好记，适合在咖啡馆被叫到。**
2. **她平时在哪混？**
  - **仓津市中央区，某栋老旧写字楼的三楼，Occurrence Labs 的办公室。窗外能看到电车轨道。**
3. **她的一天怎么过？**
  - **上午10点到公司，泡杯咖啡，翻当天的报纸和邮件。下午约作者在楼下咖啡馆见面。晚上可能去电器街的二手书店淘点旧杂志。**
4. **她的包里有什么？**
  - **翻盖手机、皱巴巴的笔记本、三支不同颜色的笔、一包薄荷糖、一把折叠伞（仓津的天气说变就变）。**
5. **她有什么怪癖？**
  - **喝咖啡一定要加两份糖。审稿时会不自觉地咬笔帽。**

## **第六步：决定外貌**

**Opcode 没有"外貌属性"——外貌由你描述。魅力（CHA）更多关乎你的气场和社交技巧，而不是长相。**

**描述你的角色时，想几个关键点就够了：**

- **身高体型：娇小、高挑、壮实、瘦削？**
- **发型发色：长发短发？直发卷发？染过吗？**
- **穿着风格：休闲、正式、街头、古板？**
- **标志性特征：总戴着一顶帽子？喜欢穿红色？有一道疤？**

**我的 Mira：**

> ***二十出头，中等身高，偏瘦。黑色短发挑染橙色。工作日穿衬衫加开衫毛衣，周末是旧T恤和工装裤。左耳戴三个银色耳环。总背着一个塞得鼓鼓的帆布包。***

## **写在最后**

**建卡没有"正确答案"。一个 INT 2 / BOD 8 的壮汉和一个 INT 8 / BOD 2 的书呆子都可以很好玩——关键是你想讲什么样的故事。**

**我的建议是：先想一个大概的人设，再填数字，最后用数字反过来丰富人设。 比如我发现自己的编辑 WIL 只有 5，那我就知道——她会在截稿日前夜崩溃大哭。这很真实，也很有趣。**

**现在，轮到你了。拿起笔——或者打开记事本——开始创造你在仓津市的第二个生活吧。**
