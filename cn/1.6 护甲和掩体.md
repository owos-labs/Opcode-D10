# 护甲

就像武器章节里说的，我们使用一个类似GOST R 50744-95 （2002）的标准来决定护甲的护甲等级（AR）。任何护甲都包含一个防护区域，其区域的护甲等级，和护甲材质。

通常来说，其是0（不提供实际防护能力）到60（NIJ IV）之间的数字。  
针对更高等级的护甲（如NIJ IV+，STANAG 4569 III，其理论上可阻止.50 AP），其具有的护甲等级可能在70以上。

任何护甲（和护甲板）都具有以下属性：**护甲名称 / 防护材料 / 主要防护区域 / 次要防护区域 / 主要防护区域AR / 次要护甲防护区域AR**。

- 防护材料：在当前版本中，其实际上没什么意义。通常来说，钢制护甲板带来更多重量，陶瓷护甲板更脆弱，UHMWPE在面对高速穿甲弹和API时性能往往没那么理想，但是更轻。我们认为这主要应该被作为RP惩罚和非关键因素，所以我们将此决定权交给GM和后续的扩展设计者，但我们的确在下面的内容中稍微提及了一些你可以进行具体操作的基础，来设计一个可以达成更均衡游戏系统的方式——你不必非要这么做，这只是一个例子，其具体实现应由你来把控。
- 主要防护区域：其硬质护甲板（如果有）覆盖的区域。
- 次要防护区域：其软质护甲材料（或内衬）覆盖的区域。

为了简化计算，我们将主要防护区域AR加上次要防护区域AR的等效值，一般来说实际上的有效防护能力低于两种护甲材质相加。

比如：  
一个包含了NIJ IV的，包含NIJ II的防弹插板背心，可能在上肢，上半身，上半腿部包含软性护甲，在上半身包含硬性护甲。  
这个护甲可能具有陶瓷 NIJ IV插板（AR 60），凯夫拉纤维（NIJ II），所以其最终数值为：

**Generic Heavy Vest / 陶瓷，凯夫拉纤维 / 上半身 / 上肢，上半身，下肢 / 65 / 25。**

一般来说，在单个部位多层不同护甲的情况，对其最高护甲值的AR区域提供+5-+10的护甲值。针对护甲防护了多个半个肢体部位的情况，将所有护甲值应用在这个肢体部位，除非攻击者决定瞄准那些没被防护的区域。

### 可选规则：材质

一般来说，当代（至2026年年初）主流的护甲插板（一般来说，从AR30开始）材料包含钢（合金），UHMWPE（超高分子量聚乙烯）和陶瓷。其中装甲钢最重但性能一般来说更稳定，但受金属疲劳和护甲形变影响，陶瓷材料可以几乎完美防护低于其防护能力的弹药且不受影响，但任何高于其防护能力的弹药会不可避免地损坏它（想想往一块玻璃上丢一团雪球和丢一块石子）。UHMWPE的唯一缺点是它是PE（聚乙烯），面对高温环境，高速和和API（穿甲燃烧）弹药，它的表现往往不尽人意。

考虑到实际上所有现代防弹插板都通常使用至少一种材料，在Opcode:// 中，"材质"属性意味着其主要吸能材料的材质。

我们提供了一个示例规则，你可以在此基础上进行进一步的扩展规则设计。

**UHMWPE** 总是具有防护规格允许下最轻的质量，将其质量下调一档，但针对任何穿甲系数等于或高于它AR的弹药，其护甲性能降低一级（10）。  
**陶瓷** 针对所有未击穿伤害，其穿甲差值每10点降低2个伤害骰而非一个，但在任何击穿的伤害情况下，其承受后续伤害时，护甲值对半计算。  
**钢质** 总是具有防护规格允许下最高的质量，但不承受任何额外惩罚。

# 掩体和遮蔽物

首先，掩体和遮蔽物不是同一种东西——但是我们在这里将其进行统一讲解。任何掩体和遮蔽物都具有AR和SSP，也就是护甲值和结构强度点数。AR决定该物体的硬度，而SSP决定该物体的强度。其单位为每平方米 / 每CM厚度，面积小于1x1平方米或厚度低于1CM的在计算中被视为具有如此大小。

掩体和遮蔽物很显然提供遮蔽，所以其可以提供不同的瞄准难度。具体调整值参考章节附表。

在一个掩体被攻击时，如果这次攻击命中了其后的目标，其AR应该在伤害阶段被加算在受击者的护甲上，并在伤害结算时同时进行掩体SSP的扣减，每点造成的伤害扣减1点SSP。如果其受到伤害的身体部位并不被遮蔽，则不扣减SSP且不进行AR增加。在一个掩体的SSP减半时，遮蔽等级（参考下表）下调一级，最低可见。在具有多个掩体的情况下，将所有掩体的AR相加，并在伤害阶段针对所有掩体扣除同样的SSP。

遮蔽物（如灌木丛）并不提供有效的吸能，所以其只能提供遮蔽，而不提供伤害减免。

# 战斗信息经济学

在Opcode:// D10中，战斗轮中的定位信息分为三类：模糊定位，精确定位，和完全定位。  
在战斗轮开始时，所有参与战斗轮的单位都对战斗轮内的任何其它单位具有至少模糊定位，直到其信息状态更新。

模糊定位意味着"有人知道此单位在场"。在模糊定位状态下，可以获知的信息包含：目标是否在场，目标已造成（outgoing）的伤害，目标的主动性。  
一个模糊定位的单位一旦进行任何足以暴露自己所在位置的行为（如清晰可闻的开火或交流），则其信息对所有可闻的对象等级上调至精确定位。针对模糊定位的单位，你无法直接对其攻击，但可以通过"我要射穿这堵墙"，或者"我怀疑他们在这个房间里，我要扔手雷"来进行有意义的伤害。作为此动作的回应，原则上DM应该进行暗骰的伤害值，但不给予有意义的反馈（如"子弹射穿了墙"）。

精确定位意味着"有人知道此单位在这个大概位置，或者通过任何信息（如射击后没有脚步声）估算出目标在这个位置，但是并没有直接目视"。攻击一个被精确定位的目标时，受到-5减值。从精确定位开始，拥有精确定位的目标可以获得已对被定位的目标造成的伤害。

完全定位通常意味着"通过任何传感器或者目视发现了目标"。攻击被完全定位的目标时一般来说无需承受额外减值。
