# 技能

## 综述

Opcode:// D10的技能包含一系列大类下的小技能，其根据不同情况使用多种属性进行检定。一般来说，列表内的属性就是绝大多数情况你会实际使用到的。

除了技能外，你还拥有专精技能。那些应用在某些情况下的技能。

我们首先将由技能开始——这是Opcode:// D10 在无扩展情况下的技能列表。

## 进行检定

你使用**1D10+关键属性+关键技能+专精* 来进行技能检定，vs. 难度。难度表如下：


| 难度    | 修正/难度值 | 描述                                                                |
| ----- | ------ | ----------------------------------------------------------------- |
| 简单    | 10     | 简单的问题——一般来说不需要进行检定的，除了这次你需要。                                      |
| 普通    | 15     | 最常见的难度，猜出一个开关如何工作，拎起一些约一倍体重的东西，进行行业内平均水平即可解决的事情，哪怕是实习生。           |
| 困难    | 20     | 你和你的角色都认为这件事绝非易事，也绝非不可能。                                          |
| 非常困难  | 25     | 需要受训行业专家执行的人物。                                                    |
| 几乎不可能 | 30     | 实际上的Mission Impossible，哪怕是对那些在领域中最有建树的人而言，ta们也需要一点运气。             |
| 承受压力  | +2     | 角色正在承受各种压力。                                                       |
| 未受训   | +5     | 角色没被训练进行这件事情。这依赖于时间——在2020年代几乎所有人都知道如何操作电脑，或者开一辆车，但是对90年代而言，没那么多。 |


### 购买技能

在我们的规则，Opcode:// D10 中，玩家使用其上限属性*5的技能点购买其初始技能，或者使用属性点总和*1.5+5进行技能购买。

在你开始研究这些技能实际上都做什么之前，我们建议你先购买技能，然后在接下来的章节内（考虑到它们对于购点来说差不多足够不言自明了）再深入继续研究。

### 大成功和大失败

在1D10=10的情况下，角色获得了大成功。针对你自己的节奏，可以让他们自动成功，或者加骰一个额外的1D10，并将出目加在原本的检定出目之上。但是一般来说，如果第二个骰子依然1D10=10，我们建议你直接判定角色成功。在叙事上这可能是某种意外因素，或者是角色本来就真的有那么强。

在1D10=1且技能检定未成功的情况下，角色获得了大失败。角色搞砸了，而且一般不太可能再进行下一次这种行为了。搞烂了开关？意外格式化了系统？都有可能，但是没人清楚。

### 购买专精

你可以使用1点技能点购买1点专精。进行有专精的检定时，除了获得额外的专精加值，你还在这一检定上获得额外的每有2点专精1点额外加值。专精也可以被用于关联领域，如你在试图维护一把步枪时，你可以将步枪专精加在你的巧手检定上。

### 长线检定

在进行一个耗时较长的检定（通常是多于一小时且偶尔持续多天的情况），你需要进行长线检定。一个长线检定包含一个检定时间，重试次数，和一个难度。  
如果一个检定比角色预期的困难，你也可以将普通检定变为长线检定。你需要在检定开始时进行一次掷骰，每隔检定时间进行一次后续掷骰，并将出目加在原本的结果上，直到角色的出目到达了预期，或者角色的耗时超出了预期，在角色获得一个大失败时，自动结束本次检定并视为失败。
