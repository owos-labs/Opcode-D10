## 远程武器

### 射弹武器

远程射弹武器使用以下模板描述：**武器名称 / 口径 / 精度 / 可靠性 / 射速 / 开火模式 / 射程 / 隐蔽性**。

任何远程射弹武器都拥有一个口径，其只能使用其口径适配的弹药。

一个例子为：

> AEK-971（KORD 6P67） / 5.45x39mm / +0 / N / 900 / SA,FA / 400m / P  
> Kriss Vector-9 / 9mm / -1 / N / 1200 / SA,FA,B 2 / 100m / C

说明AEK-971是一把使用5.45x39mm弹匣，具有普通精准度，普通可靠性，每分钟可以发射900发且很难隐藏的武器。

**精度**  
为在其射击骰上带来的加值。

**可靠性**  
为其在射击骰时大失败（1D10<[不可靠（U）:2 | 一般（N）:1 | 非常可靠（V）:不会故障]）时的故障率。

**隐蔽性**  
隐蔽性"其能多好在各种情况下被隐蔽"的指标。其中包含：

- E（优良）: 如Glock 19X, Walter PPK类的便携手枪。
- G（出色）：如被折叠枪托且没有额外附件，且不包含弹匣的AKS-74U，MPX（4.5'枪管，折叠枪托），Colt Cobra .357
- C（普通）： 包含弹匣的AKS-74U，AR平台手枪
- P（较差）：10.5' 枪管的AR，包含折叠枪托的AK平台。
- N（不可隐蔽）：任何高于10.5'枪管的AR，或全尺寸AK平台。

### 弹药

在Opcode中，射弹武器本身通常不造成伤害（除非你认为其应该被用于近战），其需要弹药来造成伤害。不同口径类别使用不同的伤害骰。我们针对穿透使用了一个类似GOST R 50744-95 （2002）标准的数值，并将其实际穿透能力的预估乘以10。  
其格式为：**名称 / 口径 / 伤害 / 穿透**  
一个例子为：

> 5.45x39mm 7N6（PS）/ 5.45x39mm / 3d6 / 30  
> 5.45x39mm 7n39 (PP BS) "针匣" / 5.45x39mm / 3d6-2 / 55  
> 9x19mm RIP / 9mm Para / 4d4 / 9  
> 9x19mm FMJ / 9mm Para / 3d4 / 15

通常来说，不同口径的弹药具有不同的伤害骰，其中：

手枪口径使用d4伤害骰，一般来说具有0-20穿透。  
中间威力步枪口径使用d6伤害骰，一般来说具有20-40穿透。  
全尺寸步枪口径使用总是带加值的d6伤害骰，一般来说具有25-60穿透。  
反器材口径（从12mm开始）使用D10伤害骰。一般来说穿透从50开始。  
火炮口径（从37mm开始）使用D10或D20伤害骰。一般来说具有至少100的穿透。

**霰弹**

一般来说，针对霰弹，在Opcode:// 中，我们使用特殊的伤害模式计算其具体伤害。

霰弹弹药包含一个新的属性：弹丸数，为标示其有效（计伤）弹丸数量的数据。

霰弹的数据格式为：**名称 / 口径 / 伤害 / 穿透 / 有效弹丸数**。

针对鹿弹（Slug），单弹头箭弹（Flechette ）和单弹头脱壳穿甲弹（Sabot），如常计算伤害并将使用其的武器的射程*2。

针对普通弹种（Buckshot），其在攻击射程的1/2内的对象时照常结算。在这部分中，我们将使用12GA #00（8.4mm）Buckshot。  
在高于1倍射程时开始，伤害骰数量减少1/4（6d3），骰两次身体部位，将命中难度降低2，在这两个伤害部位分别计算一半的原本破甲和伤害，对0.5m内的目标进行同样的事情。  
在高于1 1/4（1.25）倍射程时开始，伤害骰数量再减少1/4（4d3），将命中难度降低5，骰三次身体部位并分别计算1/3的原本破甲破甲和1/3的伤害。对0.9m内的目标进行同样的事情。  
在高于1 1/2（1.5）倍射程时，将命中难度降低7，伤害骰数量减少一颗（2d3），在全身均摊每个身体部位1的伤害（但不多于其弹药的弹丸数），对1.3m内的目标进行同样的事情。

远于那的情况下，在单个身体部位造成最低伤害（如针对12GA #00 鹿弹的情况，造成 min(1d2)=1），将命中难度降低10，对1.5m内的目标进行同样的事情，在2倍射程以外，无论其原本伤害是多少，不造成任何伤害。

没有人想真的数一发12GA 鸟弹里有多少弹丸......所以我们简化了一些规则。  
12GA鸟弹（无论其实际口径）在1m距离内造成2D10伤害，在1m外造成1d10-5，在5m内造成1d10伤害，20GA鸟弹造成1D10，1D10-3，1D10-5伤害，在5m外造成1伤害，在7m外不造成任何伤害，且一直具有1的穿甲。

以下提供一系列常见的霰弹弹种。

> 12GA RIP Slug / 12GA / 6d6 / 15  
> 12GA Lead Slug / 12GA / 4d6 / 25 / 1   
> 12GA AP Sabot / 12GA / 2d6+1 / 35  
> 12GA #0 (9.1mm) Buckshot / 12GA / 4d6 / 15 / 6  
> 12GA #00 (8.4mm), #000 (8.1mm) Buckshot / 12GA / 8d3 / 7 / 8  
> 12GA #1 (7.6mm) Buckshot / 12GA / 6d4 / 9 / 8  
> 12GA #4 (6.1mm ）Buckshot / 12GA / 8d3-2 / 13 / 9  
> 20GA #1 (7.6mm)  Buckshot / 20GA / 5d4 / 7 / 8  
> 20GA #3 (6.1mm) Buckshot / 20GA / 6d3 / 5 / 8

### 可选：掩体，未穿透和过穿

使用不同类型的掩体，可以防止绝大多数远程武器攻击。弹药对肉体的毁伤效应通常来说通过子弹动能转移造成的腔体（空腔效应）来实现，这也意味着只有在合适的穿透情况下，一颗子弹才能达到其最理想的毁伤效能。

在你进行护甲结算前，进行一次比对：甲弹对抗后最后的穿透结果每高10点（如一发5.56x45 M855A1具有45穿透，目标穿着NIJ IIIA（30AR）护甲，多出了15净穿透），最后的伤害结算降低一个伤害骰（M855A1具有3D6+1伤害，最后结算时只造成2D6+1）。无论如何，一次过穿的射击至少保留一半原始伤害骰，向上取整。

如果一次攻击未能穿透，这次攻击只造成1/4个伤害骰的伤害，并应用独立的调整值（如一次未穿透的5d6+2射击造成1d3+2伤害），但不可低于1，且这次攻击不会触发任何毁伤效果（见健康章节）。

针对不同掩体的材质，其可以完全阻挡（弹药穿透低于掩体的AR），未阻挡但未穿透（掩体AR低于弹药穿透，但厚度低于其最大可能伤害），穿透。  
在被阻挡但未穿透的情况下，该子弹转而对掩体造成伤害。  
在穿透的情况下，计算穿透时计算减掉掩体AR的穿透值后向下取整到整十的穿透值并降低其不同掩体类型厚度值的伤害骰。  
以下是一个例子：

> 来自Arctic International AW 的 .338 Lapua  Magnum 造成6D6-2伤害，具有72穿透。  
> 其穿透了一堵厚度为20cm的水泥墙面（50AR，20厚度），在穿透后只剩余了20穿透。  
> 目标未着甲（AR=0），所以拥有20点过穿。  
> 弹药本身原本造成6D6-2伤害，降低来自20过穿和20掩体抵销的4个伤害骰后只造成2D6-2伤害。  
> 掷骰，得出了4伤害。  
> 这一发弹药造成了一个蛮肮脏的贯穿伤，但是受击者依然活蹦乱跳，并在意识到这里有狙击手后准备开始其反击。

未穿透的情况下，对掩体造成的伤害为原本伤害的一半。  
从反器材口径开始，因为其巨大的枪口动能，其不再受过穿影响。  
从火炮口径开始，针对AR低于穿甲弹药口径*10（如37mm, 370AR）且其穿透值可以造成贯穿的掩体，其不再受到掩体的穿甲惩罚。

## 爆炸物

> "你知道么，小子，这可不是什么FPS，处理CQC的最好方法就是别在那里。"

爆炸物永远忽略护甲并对其影响范围内的目标造成全额伤害。针对不同类型的爆炸物（如高爆，破片，热能）有不同的结算方式。如果战斗负载为使用射弹武器发射（如M203 40mm UBGL发射的40mm M441高爆榴弹），其使用射击技能进行检定。针对手榴弹，其使用运动/投掷进行检定。如果你的目标（或者投掷落点）在引信距离内，那么任何在毁伤半径的单位都可以进行一次对抗你投掷成功数的敏捷豁免来将其重新投出，并如常进行其投掷检定。

  
其格式为：  
名称 / 致死距离(半径) / 次要毁伤距离(半径) / 类型（HE：高爆，F：破片，T：热能） / 发射类型（B：弹道，T：投掷） / 伤害 / 持续时间 / 引信距离  
次要毁伤半径从致死距离边缘起算。以下是一系列例子：

> 40x46mm M441 / 2m / 2.5m / F / B / 2D6 / 0 / 15m  
> RG-60 / 3m / 0.5m / HE / T / 3D6 / 0 / 5m  
> F-1 / 1m / 3.5m / F / T / 2D6 / 0 / 5m

所有在有效范围内的单位应该进行一次敏捷豁免，并在成功的情况下将伤害降低一级（致死变为致伤，致伤变为无伤害），这视为目标眼疾手快逃离了爆炸范围。

### 高爆

这类爆炸物通过压力差和冲击波造成伤害，如RG-60温压手榴弹或硝化甘油（2020年的硝化甘油爱好者，你们好呀）。其具有一个致死距离，一个来自压力差和冲击波的次要毁伤距离。致死距离意味着任何在落点中的生物目标（无论有甲或无甲）均会被直接击杀，并在致伤距离内造成其标定的伤害。这类武器不对密闭且封闭墙体后的对象造成伤害，但是会摧毁任何硬度（AR）低于其最大可能伤害的，位于致死距离内的墙体。

### 破片

这类爆炸物通过初始的压力差和后续的破片或钢珠造成伤害。其具有一个致死距离和一个来自破片的次要毁伤距离。在破片距离内的对象应进行运气豁免，否则受到标记的伤害。  
这类爆炸物不对密闭（如在致死距离内）或封闭（如在致死距离外）墙体后的对象造成伤害，但是会对任何硬度（AR）低于其最大可能伤害的，位于致死距离内的墙体造成伤害。

### 热能

这类爆炸物（如铝热剂，白磷弹，燃烧弹）通过黏着在目标上造成持续伤害。在vs. 投掷者攻击检定的敏捷豁免失败的情况下，其每轮造成标称的伤害。其致死距离意味着必定会被沾染的距离，次要毁伤距离内的对象在距离时，受到一次伤害。

绝大多数火炮口径武器同时拥有爆炸物和射弹武器的毁伤效果。

以下是一个例子：

> 防御者和进攻者在一个狭窄的楼道僵持。双方人数相仿。  
> 进攻者的突破手从背心中摸出一个RG-40，随着一声"Suprise Motherfucker"丢向了楼道中的另外一方。  
> 进行命中投掷后得到20点，成功，落点的两个防御者位于致死距离内，一个位于致伤距离内。  
> 三个防御者投掷反射豁免，REF+运动+1D10，21，19，21。三个防御者四散而逃，但其中一个没能在引信结束前逃离。  
> 针对从致死距离中逃离的目标，其受到8伤害，在身体上按照比例平均分配后未能致死（全身受到1伤害）。  
> 现在三个防御者中的一个成了200号货物，一个成了300号货物，还有另外一个带着颤抖的手从自己的口袋中摸出最后一颗M67。

### 其它投掷物

其它投掷物—— 一般来说诸如烟雾弹，震撼弹，红外增幅弹，照明弹，和荧光棒。这些东西通常需要一个移动动作或者一个标准动作来投掷。

从烟雾弹被投出的下一轮开始，烟雾弹为其落点附近影响范围内的区域提供不同等级的遮蔽。  
在室内环境下，其可以持续通常来说至少两分钟，在室外为60秒，并且根据风向和风力，可以为最长20米区域提供1/3高度遮蔽，7.5米区域提供1/2高度遮蔽，或者2.5米区域内的完全遮蔽。在室内的情况下，通常来说提供全身遮蔽并且阻挡视野（即下调二级定位精度）。  
此遮蔽被应用在针对烟雾对侧单位的情况，并对烟雾内单位总是应用，烟雾内单位针对烟雾任意一侧的单位也应使用此遮蔽调整。  
其在非封闭环境（或者说半开放空间）下可以被一颗在其范围内被引爆的高爆或者破片爆炸物驱散。

武器改装，武装暖暖，无论你怎么叫它。  
在Opcode:// 中，我们将实际的武器改装（和暖暖）留给用户，只提供一系列样例模板。  
任何武器具有一个瞄具槽，一个侧瞄具槽，至多三个配件槽，一个下挂槽，一个枪口槽，一个枪托槽，一个枪体槽，枪管槽，和一个弹匣槽。我们鼓励GM来为ta们玩家的武器自写一些改装规则。

### 枪体

枪体是武器的整体枪身改造。其一般来说包含上机匣（通常提供精准度和可靠性加成），现代化 / 一体式配件（提供精准度和也许更多槽位），和其它内容（比如智能枪，如果你来自一个近未来或者未来世界设定，口径改造）。

### 配件

在这里放置激光 / 手电 / 测距仪之类的配件。任何（如果你想）护木片——提供装潢效果，额外的导轨（如果你在意cosplay）。

### 下挂

需要任何护木或枪管槽位的下挂配件，如UBGL或者握把。如果你使用了一个下挂武器，此武器一般来说只需要自由动作即可切换，而非移动动作。

### 瞄具

获得更高的射程属性或精度，代价是降低瞄具之外的射程和精度。

### 侧瞄具

装配一个侧瞄具来忽略高倍率主瞄具的惩罚。切换需要至少一个移动动作。

### 枪口

枪口配件（提供消音，消焰，或者其它类似的东西），一般来说针对武器的精准度加值有改变。消音器一般来说降低隐蔽性。

### 枪托

让它变得更好看，移除枪托来获得隐蔽性，并且让武器变得更不稳定。

### 枪管

以牺牲隐蔽性和可靠性为代价，换取额外的距离和精度。

除此之外，你可以以牺牲隐蔽性为代价，为你的武器加装更大的弹匣。

### 弹匣

在本槽位内应用你的弹匣改装。原则上而言，你需要单独的弹匣物品，但是实际上大差不差......随你了。

## 近战武器

近战武器——白刀子进，红刀子出。  
相对来说比较简单——近战武器的模板是 **武器名称 / 伤害 / 所兼容的技能 / 所兼容的属性 / 穿甲 / 最小BOD需求 / 隐蔽性 /  附加动作（0）**，要注意的是很多武器使用其独特的技能（如武士刀使用剑道，砍刀使用白刃，而西洋剑使用双手剑技能来进行检定）。

所有近战武器造成一个特定的伤害。以下提供一系列模板。

武器的体积决定了其伤害骰（一般而言，D4，D6和D8），其质量决定其伤害骰数量，临时武器同样应用这些限制。

> 匕首（和小型刃类武器） / 2d4 / 白刃-搏斗-武术 / REF, BOD / 10 / 2 / E / 0  
> 狗腿刀（和小-中型刃类武器）/ 3d4 / 白刃-生存 / REF, BOD / 15 / 3 / G / 0  
> 阔刀（和中型刃类武器）/ 2d6 / 白刃 / 15 / REF / 3 / G / 0  
> 双手剑（和大型刃类武器）/  3d6 / 剑术 / BOD / 20 / 4 / N / 0

一些武器可以适用多种技能，但在进行检定时只能同时使用一个技能和其专精检定。

近战的战斗骰为：**武器关键属性+武器技能+专精+武器伤害 vs. 防御关键属性+防御关键技能+专精+1D10**。

在开始时，攻击者和防御者应声明自己的攻击和防御位置，头部，上半身或下半身之一。如其位置相同，防御者获得额外的1D10在防御骰上。  
如攻击者造成了正伤害，其可以将伤害应用在其掷骰前声明（但合理）的位置。否则进行一个1D10来决定位置。伤害结算时，计算穿甲和护甲。一旦目标区域的护甲高于武器的穿甲，不造成伤害。否则造成攻击者成功数的伤害。  
如攻击者的掷骰得到大失败，防御者可以立即进行一次攻击检定。  
我们鼓励实际的武器和武术技能设计者为近战武器提供免费的附加动作。

徒手攻击不与护甲AR进行通常的穿甲比较。其代表抓取、关节技、压制、窒息、攻击护甲间隙以及其它绕过硬质防护的近身行为。忽略护甲，攻击者每具有高于5的两点BOD（向上取整），造成额外1D4伤害，否则造成1D4伤害。

以下是一个例子。

> 防御者走投无路，亮出了腰间的Safari（ S〇g Safari 13' / 2d6+2 / 白刃 / 20 / BODY / 4 / G / 0），决定在墙角决一死战。  
> 攻击者心领神会，也丢下手里打空备弹的步枪，从防弹衣（NIJ III+，防护部位 身体，AR 45）前的刀鞘中拔出军刀（Ka-Bar M9 / 2d4 / 白刃-搏斗-武术 / REF, BOD / 10 / 2 / E / 0）。  
> 双方的眼神交汇，防御者的动作快一拍（20主动性），而攻击者没料到对面的爆发力在长达十分钟的追击后依然如此强劲，被吓了一跳（14主动性）。  
> 说时迟那时快，防御者向着攻击者的肩膀砍去（11 vs. 20）。  
> 料到他抬手动作的攻击者定神，闪身，然后借着力气向着他的腰间刺去（15 vs. 19），但最后还是慢了半拍。  
> 防御者调转刀口向着他缺乏护甲的颈部调转刀锋(23 vs. 19，4伤害)，刀刃末端的血痕随着倒地声响起凝结。  
> 防御者擦擦刀，然后因为肾上腺素的褪去终于坐在地下。  
> 房间里沉寂无声，只有门外走廊对面街道的车声透过防御者的心跳可闻。
